# 二年级上册 · 语文园地四 · 日积月累

小学语文（部编版）二年级上册 **第四单元 · 语文园地四 · 日积月累** 配套教学资源包。
收录四副经典写景对联，融合**插图、朗读音频、作者出处注解**，
适用于课堂教学、家庭诵读与传统文化启蒙。

## 四副对联

### 第一联 · 山水篇
> 有山皆图画，无水不文章。

出自清代**梁章钜**《楹联丛话》，原为杭州涌金门外"三雅园"茶楼题联。以"图画""文章"喻山水之美。

### 第二联 · 塞上江南
> 白马西风塞上，杏花烟雨江南。

出自现代画家**徐悲鸿**手书楹联（题画联）。教材节取后两句：上联写北方边塞苍凉壮阔，下联写江南水乡柔美诗意。

### 第三联 · 沧浪亭集句
> 清风明月本无价，近水远山皆有情。

苏州沧浪亭名联，属"集句联"：
- 上联取自**欧阳修**《沧浪亭》："清风明月本无价，可惜只卖四万钱"
- 下联取自**苏舜钦**《过苏州》："绿杨白鹭俱自得，近水远山皆有情"
- 由清代梁章钜集句，俞樾书镌于亭柱

### 第四联 · 回文联
> 雾锁山头山锁雾，天连水尾水连天。

写景**回文联**（正读倒读皆通），描绘福建厦门鼓浪屿一带大雾弥漫、水天一色之景。作者不详，教材标注为佚名。

## 使用建议

- **听读**：播放 `《日积月累》.mp3`，跟诵读节奏与停顿。
- **看图**：结合每句对应的 `*.png` 插图，体会诗意画面。
- **讲出处**：参考 `日积月累` 文本中的作者介绍，为学生讲解对联背后的文化故事。
- **拓展**：第四联是回文联，可引导学生尝试创作 / 发现更多回文句（如"客上天然居，居然天上客"）。
